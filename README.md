# AtlasA1-media

Cedar/OMX/PVR media integration and browser transport sources for the T736 Aurora/AtlasA1 board.

The native player uses Cedar hardware decoding and the PowerVR GLES2 renderer. [Player and build instructions](tools/player/README.md) · [Playback measurements and display status](docs/PLAYBACK.md)

This repository contains public source, patches, tests, and manifests. Vendor codec/GPU libraries remain external inputs.
